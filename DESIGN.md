# DESIGN.md - Adwa Najmi Engineering Portfolio

## 1. Identity & Personality
- **Subject:** Adwa Najmi, Software Engineer & Laravel Developer (Kuala Lumpur, Malaysia).
- **Core Value:** Crafting resilient enterprise web applications, real-time sync pipelines (Rymnet / SWCorp), and high-volume database architecture.
- **Personality:** Pragmatic, disciplined, meticulous, and authentic. No superficial hacker gimmicks or marketing buzzwords.
- **Tone:** Professional, direct, evidence-focused.

## 2. Antislop Dials
- **ENERGY:** `2` (Balanced: confident, sharp, modern without loud neon saturation).
- **RHYTHM:** `2` (Structured narrative: distinct visual weight separating flagship enterprise platforms from supporting prototypes and career milestones).
- **MOTION:** `1` (Calm: smooth state transitions, zero continuous background loops, fully respectful of `prefers-reduced-motion`).

## 3. Color System
The palette is built on deep slate navy with a focused electric sky accent, designed for strict WCAG AA contrast compliance across both dark and light modes.

### Dark Theme (Default)
- **Base Deep Background:** `#0a0e17`
- **Surface Elevation 1:** `#111827` (Slate 900)
- **Card Surface:** `#162032` (Slate 800+)
- **Card Hover / Border Subtle:** `rgba(255, 255, 255, 0.08)`
- **Primary Accent:** `#38bdf8` (Sky 400 - high contrast on dark)
- **Secondary Accent:** `#818cf8` (Indigo 400)
- **Text Primary:** `#f8fafc` (Slate 50 - contrast 17.5:1 against deep)
- **Text Secondary:** `#cbd5e1` (Slate 300 - contrast 9.2:1 against deep)
- **Text Muted:** `#94a3b8` (Slate 400 - contrast 5.8:1 against deep, exceeds 4.5:1 WCAG AA)

### Light Theme
- **Base Deep Background:** `#f8fafc` (Slate 50)
- **Surface Elevation 1:** `#ffffff`
- **Card Surface:** `#f1f5f9` (Slate 100)
- **Card Hover / Border Subtle:** `rgba(15, 23, 42, 0.08)`
- **Primary Accent:** `#0284c7` (Sky 600 - high contrast on light)
- **Secondary Accent:** `#4f46e5` (Indigo 600)
- **Text Primary:** `#0f172a` (Slate 900 - contrast 16.8:1 against light)
- **Text Secondary:** `#334155` (Slate 700 - contrast 9.5:1 against light)
- **Text Muted:** `#475569` (Slate 600 - contrast 6.9:1 against card, 7.2:1 against light bg, exceeds 4.5:1 WCAG AA)

## 4. Typography
- **Display & Headings:** `Space Grotesk`, sans-serif (deliberate geometric character for headers).
- **Body:** System / sans-serif fallback with comfortable line-height (1.7) for maximum readability.
- **Code & Metadata:** `JetBrains Mono`, monospace (used exclusively for dates, file counts, and technical badges, not decorative sentence labels).

## 5. Composition & Hierarchy
- **Hero:** Personal introduction focused on engineering achievements with genuine project metrics and immediate access to work and resume.
- **Work Showcase:**
  - **Flagship Systems:** EMS v2 Modules, Kira+ Tax Intelligence, and Bably receive prominent featured visual weight.
  - **Supporting Work:** Filterable grid with accessible keyboard triggers (`role="button"`, `tabindex="0"`).
- **Journey:** Chronological career milestone timeline with clear date ranges.
- **Contact:** Clean, direct contact channels with verified links and active email CTA.
